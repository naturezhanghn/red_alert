# 赤潮防线 · Red Alert: Frontline

一个无需安装的浏览器即时战略小游戏。当前玩法采用“1V7 山巅防守”结构，玩家在高地建造防御设施、部署守卫，迎击七方军团的自动攻山。

## 操作

- 左键选择单位
- 右键在地图上移动已选择的单位
- 建造采矿车、兵营和哨戒炮，采矿车会自动产生资金与矿石
- 使用“部署突击队”补充战力，“紧急维修”恢复指挥中心
- `Space` 或右上角按钮暂停行动

## 本地运行

```bash
npm run build
npm run serve
```

打开 `http://localhost:4173` 即可开始游戏。
